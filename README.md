## 🌟 Key Features & Recent Upgrades

- 🚀 **Redesigned Hero Section**:
  - Updated headline: *"We Build Digital Solutions That Grow Your Business"*.
  - Added interactive feature badges: 🌐 Website Development, 📱 Mobile App Development, 📈 Digital Marketing.
  - Renamed CTAs: *"Get Free Consultation"* & *"Explore Services"*.

- 💼 **Modular Services Architecture**:
  - **Overview Cards**: 3 large service category cards (Website Development, Mobile App Development, Digital Marketing) with direct smooth-scroll links (`#website-development`, `#mobile-app-development`, `#digital-marketing`).
  - **Dedicated Website Development Section**: 6 specialized web solution cards (Business, E-Commerce, Corporate, School, Hospital, Portfolio) with feature tags and instant quote triggers.
  - **Dedicated Mobile App Development Section**: 4-tier pricing grid (Basic `₹14,999`, Standard `₹29,999` Popular, Premium `₹49,999`, Enterprise `Custom Quote`) with mobile illustrations, timelines, and feature checklists.
  - **Dedicated Digital Marketing Section**: 6 strategy cards (SEO, Social Media, Google Ads, Meta Ads, Content Marketing, Email Marketing) with orange accent badges and hover animations.

- 🧮 **Interactive Multi-Category Project Price Calculator**:
  - Added 3 interactive domain tabs: **Website**, **Mobile App**, and **Digital Marketing**.
  - Dynamic base package cards and add-on checkboxes recalculating investment costs and turnaround times in real time.
  - One-click package ordering pre-fills contact form selections.

- 📋 **Contact Form with Dependent Dropdowns**:
  - Replaced single dropdown with **Service Category** and dependent **Service Type** dropdowns.
  - Automatic dropdown population, state resetting, HTML5 validation, and smooth pulse transitions (`@keyframes dropdownPulse`).
  - Pre-selection integration: Clicking any card button ("Get Quote" / "Get Started" / "Learn More") scrolls to the form and pre-selects the corresponding category & service type.

- 🌟 **Redesigned "Why Choose Us" Section**:
  - 6 modern performance cards (Fast Delivery, Secure & Reliable, SEO Friendly, Mobile Responsive, Dedicated Support, Client Satisfaction) with icon badges and hover lift.

- ⚡ **Enhanced "Technologies We Use" Section**:
  - Refined UI spacing, card elevation shadows (`--shadow-card`, `--shadow-hover`), icon rotation micro-interactions, and tab filtering (Frontend, Backend, Database, Tools).

- 🌙 **Navy Blue Dark Mode**:
  - Seamless theme switcher with a deep Navy Blue color scheme (`#0A1128`), persistent `localStorage` preference, and smooth color transitions.

## 🛠️ Tech Stack & Technologies

| Layer | Technology |
| :--- | :--- |
| **Structure** | [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) (Semantic HTML5, Accessibility, ARIA Attributes) |
| **Styling** | [Vanilla CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (CSS Variables, Flexbox, Grid, Glassmorphism, Keyframe Animations) |
| **Scripting** | [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript) (DOM Manipulation, Dependent Dropdowns, Tab Switching, Dynamic Price Calculation, Toast Notifications) |
| **Typography** | [Google Fonts](https://fonts.google.com/) (`Outfit` & `Plus Jakarta Sans`) |
| **Icons** | [FontAwesome 6.4](https://fontawesome.com/) |


2. **Open the project**:
   Simply open `index.html` in your web browser of choice, or run with VS Code **Live Server**.
